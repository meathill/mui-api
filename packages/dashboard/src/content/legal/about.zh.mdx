# 关于 MuiRouter

> 一个 API Key，连接每一个大模型。无需翻墙，无需订阅，按 token 计费。

## 愿景

大模型的分化速度远超任何单一团队的接入速度。MuiRouter 想做你产品底下的那层**无聊但稳定的路由层**：

- **一个 Key，全家桶。** OpenAI、Claude、Gemini、Grok、MiMo 等都在同一个 OpenAI 兼容端点后面。
- **边缘原生。** 走 Cloudflare 300+ 节点，离用户更近，而不是离你的 VPN 更近。
- **用多少付多少。** 没有席位、没有打包、没有过期积分。充值、调用、查 `GET /v1/usage`，计费就这么简单。
- **MCP 原生。** 同一个路由也讲 Model Context Protocol（streamable HTTP），Claude Code、Cursor、Cline 等任何 MCP 客户端都能复用同一套 Key 与钱包。
- **为我们自己的下一个产品而建。** MuiRouter 是 Meathill Studio 下一代 AI 产品的底座。能稳定支撑我们和朋友，就能支撑你。
