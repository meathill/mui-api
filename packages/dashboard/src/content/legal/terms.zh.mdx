# 使用协议

**生效日期：** 2026 年 9 月 1 日 · **版本：** 2026-09-01 · **运营方：** Meathill LLC

> 本服务是面向开发者的 AI 网关。注册账号或调用 API 即表示你同意本协议。

## 1. 服务说明

MuiRouter 提供 OpenAI 兼容的 AI API 路由与 MCP 服务，将你的请求转发到上游供应商（OpenAI、Anthropic、Google AI Studio、Moonshot AI、xAI、Xiaomi MiMo、Cloudflare Workers AI 等）。我们不会用你的提示词训练模型。你只需持有本站的 API Key（`sk-gw-`）即可统一路由、计费与计量。

## 2. 账号与 API Key

- 需提供真实的联系信息并妥善保管凭证。
- 账号下所有 API Key 与 OAuth 令牌产生的行为由你负责。
- 严重违反本协议或上游供应商使用政策时，我们有权暂停账号。

## 3. 合规使用

不得利用本服务从事违法、侵权、生成非法内容或攻击本服务及上游的行为。触发上游风控的模型、提示词或账号可能被限流或封禁。

## 4. 计费

- 按 token 计费，无订阅。价格以请求时刻控制台中该模型的配置为准。
- 充值进入钱包余额，余额永不过期。
- 支付由 Stripe Checkout 处理，计价货币为 USD。

## 5. 额度与消耗

- 免费体验额度（如开启）为限时推广额度，仅限指定模型抵扣，不具现金价值。
- 一旦上游返回响应，计量即视为完成。Token 数以上游返回为准。

## 6. 退款策略

我们希望你先试用再充值；同时，支付与调用模型时已产生真实成本。

### 6.1 可退条件

- 仅**未消耗的预付钱包余额**可退。
- 需在**充值后 30 天内**通过 `support@muirouter.com` 申请。
- 免费推广额度不可退款。

### 6.2 扣减项

审核通过的退款按以下公式计算：

```
可退金额 = max(0, 充值金额 - 已消费 - 充值金额 × 5.5% - 汇兑/通道损失)
```

- **Stripe 手续费：** 充值金额的 5.5% 不退（Stripe 通道成本，刷卡与加密通道统一费率）。
- **已消费金额：** 钱包中已结算的推理、图片、视频等计量费用全额扣除。
- **汇兑/通道损失：** 银行或支付通道产生的汇率转换、跨境或加密通道费用由用户承担并扣除。

### 6.3 最低金额与到账

- 单次可退最低金额为 **$5.00**，低于此金额不予处理。
- 退款原路返回，实际到账时间取决于 Stripe 与发卡行（通常 5–10 个工作日）。
- 处理前可能要求做账号校验。

### 6.4 拒付

未先联系客服直接发起 chargeback 视为违反本协议，可能导致账号暂停。

我们依托 Cloudflare 全球边缘网络追求高可用，但不承诺 100% 不中断。上游供应商的中断、限流或政策变更不在我方控制范围。

在法律允许的最大范围内，本服务按“现状”提供。因本服务产生的任何索赔，我方的合计责任不超过索赔前 30 天内你的已付金额。
