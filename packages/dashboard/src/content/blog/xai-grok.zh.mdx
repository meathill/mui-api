2026 年 7 月 8 日，xAI 发布了 Grok 4.5——它的新旗舰模型，和 Cursor（这个编程编辑器上个月刚被 xAI 以 600 亿美元收购）联合训练，直接对标 Claude Opus 4.8。Elon Musk 把它形容为「一个 Opus 级的模型，但更快、token 效率更高、成本更低」。发布当天就放这么大的话不算小事，而且它是建立在 Grok 整条产品线近期一连串改进之上的——大得多的上下文窗口、原生视频输入、更快的 Imagine 视频生成——再加上一个新的分发渠道：Grok 现在可以直接通过 Cloudflare AI Gateway 调用了。

正是最后这一点让我们能很快跟进。今天我们把 `grok-4.5`、`grok-4.3` 和 `grok-imagine-image` 加进了 MuiRouter 模型目录，通过你已经在用的 `/v1/chat/completions` 和 `/v1/images/generations` 端点即可调用——和 OpenAI、Anthropic、Gemini 走的是同一套接口。

## xAI 这次发了什么：Grok 4.5

Grok 4.5 构建在 xAI 1.5 万亿参数的 V9 底座之上，现在是 Grok Build 里的默认模型。定价 $2/百万 input token、$6/百万 output token，推理速度约每秒 80 token。

xAI 官方给出的发布当天 benchmark，对比 Claude Opus 4.8：

| Benchmark | Grok 4.5 | Opus 4.8（max） |
| --- | ---: | ---: |
| SWE Marathon（pass@1） | 29.0% | 26.0% |
| Terminal Bench 2.1 | 83.3% | 78.9% |
| SWE-Bench Pro（解决率） | 64.7% | 69.2% |

真正值得琢磨的数字不是输赢那一栏，而是 token 效率：在 SWE-Bench Pro 上，xAI 说 Grok 4.5 平均只用 15,954 个 output token 就能解决任务，而 Opus 4.8 在同一个 benchmark 上要用 67,020 个——差了 4.2 倍。如果这个数字在真实工作负载里也成立，那么单 token 价格更高，不一定意味着单任务成本更高。

有一点需要说清楚：这些是 xAI 自己发布页上的数据，还没有第三方独立验证。同日发布出这种情况很正常。把它当作「厂商的说法」来读，任何真正要依赖的能力，请先在自己的工作负载上验证一遍再动工。

## Grok 系列的其它部分

Grok 4.5 不是这段时间唯一的动作。仍然留在目录里的 `grok-4.3`——作为更大上下文的选项——支持 1M token 窗口和原生视频输入，还能直接生成 PDF、表格和幻灯片。Grok Imagine 升级到 1.5 版本，能生成 720p、24fps、带原生同步音频的视频，发布后一度登顶第三方图生视频榜单。xAI 还上线了 21 种多语言语音，语音转文字 API 也已 GA，覆盖 25 种语言。这些都不是这周的头条，但正是 Grok 4.5 站上去的地基。

## 我们在 MuiRouter 里加了什么

这次先上三个模型：

- **`grok-4.5`**——xAI 的新旗舰。任何 agentic 或编码相关的场景，建议先拿它试。
- **`grok-4.3`**——1M 上下文选项，当 4.5 的 500K 窗口不够用时可以切过去。
- **`grok-imagine-image`**——文生图，走的是你已经在用的 `/v1/images/generations` 接口形状，和 `gpt-image-2` 完全一致。

接入方式和 MuiRouter 上的 OpenAI、Gemini 一样，都经由 Cloudflare AI Gateway 转发——你这边不需要单独开 xAI 账号或管理 key。当前每 token 单价见[定价页](/pricing)，那里的数字会和我们实际计费口径保持同步；比起博客里写死的数字，请以那个页面为准。

视频生成（`grok-imagine-video`）这次没有一起上。它是异步任务型 API——先提交请求，再轮询结果——和我们现在路由的其它模型的接入形状完全不同。它在我们的路线图上，等做完会单独写一篇。

## 这对开发者意味着什么

- Grok 4.5 是发布当天对一个成熟模型的挑战性宣称，还不是定论——真正投产前，请先用你自己的 agentic/编码工作负载跑一遍，不要直接把 benchmark 表当采购依据。
- 如果 token 效率在你的 prompt 上也成立，即便单价更高，成本账也会跟着变——值得直接测一下。
- `grok-4.3` 的 1M token 窗口，值得拿去测试那些你之前因为窗口不够、不得不切分输入的任务。
- `grok-imagine-image` 可以直接接入任何已经围绕 `/v1/images/generations` 搭建的工作流。

## 这对 MuiRouter 用户意味着什么

每次我们加一个新 provider，故事都是一样的：你的集成不需要变。一个 API key、一种请求形状，模型目录在底下自己长大。今天加上 Grok——恰好是它新旗舰发布的同一天——意味着你现在就可以直接拿 `grok-4.5` 和你正在跑的模型做对比：同一套计费、同一套限流、同一个账号，不需要为了试试合不合适而单独接一套新集成。

## 结论

Grok 4.5 在发布第一天就放出了一个分量不轻的宣称：一个带着 Cursor 编码基因、对标 Anthropic 前沿档位的 Opus 级模型。这个宣称能否经得起独立验证，现在还不好说——但现在你只需要一个 MuiRouter API key，就能把它和你已经在跑的所有模型放在一起对比，搞清楚答案的成本，只是改一个 model 名字而已。
