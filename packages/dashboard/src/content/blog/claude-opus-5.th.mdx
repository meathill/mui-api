เมื่อ 24 กรกฎาคม 2026 Anthropic เปิดตัว Claude Opus 5 ตำแหน่งอย่างเป็นทางการ: ความสามารถดิบอาจต่ำกว่า Fable/Mythos เล็กน้อย แต่ราคาเข้าถึงง่ายกว่า ในระยะยาวอาจทำหน้าที่เป็นตัวลงมือประจำวันใต้ Fable Anthropic บอกว่านี่คือโมเดลที่**กระตือรือร้นและตรวจงานตัวเองได้ดีขึ้น** ใกล้เคียง Claude Fable 5 ด้านการเขียนโค้ดและงานความรู้ **ในราคาครึ่งหนึ่งของ Fable 5** — เท่ากับ Opus 4.8 คือ $5 / $25 ต่อล้านโทเคน

สำหรับนักพัฒนาทั่วไป การอัปเดตของ Anthropic ทุกครั้งน่าติดตาม หลายเดือนที่ผ่านมา Fable แรงแต่แพง หายาก และมักโดน safety classifier ตีผิดทาง; หลัง Fable ออก ข่าวลือว่า Opus 4.8 “ถูกลดสติ” ดังขึ้น Opus 5 ในที่สุดก็ให้ความหวังบ้าง: **ราคาเท่าเดิม ความสามารถก้าวใหญ่**

MuiRouter รองรับ `claude-opus-5` แล้ว API Key เดิม path เดิม `/v1/chat/completions` และ `/v1/messages` — แค่เปลี่ยนชื่อ model แล้วลอง

## สรุปการอัปเดตของ Anthropic

จาก[ประกาศ Claude Opus 5](https://www.anthropic.com/news/claude-opus-5) และ [system card](https://www.anthropic.com/claude-opus-5-system-card):

- รหัสโมเดล: `claude-opus-5` ใช้ได้ทั้ง API, Claude Code และ Claude Platform
- **ค่าเริ่มต้นใหม่บน Claude Max** และโมเดลแรงสุดบน Claude Pro ตอนนี้
- ราคาเท่า Opus 4.8: input $5 / 1M tokens, output $25 / 1M tokens
- **Fast mode** ทางเลือก: ความเร็ว ~2.5× ของโหมดปกติ ราคา 2× ฐาน
- โฟกัส: agent ระยะยาว, วิศวกรรมซอฟต์แวร์, งานความรู้ และการตรวจทาน–วนซ้ำเชิงรุก ไม่ได้โฟกัส cyber โจมตีแบบ Mythos จึงไม่ต้องเปิดแบบ “พาร์ทเนอร์เท่านั้น”

Anthropic ชัดเจนว่าในงาน cybersecurity exploitation Opus 5 ถูก**ตั้งใจ**ให้ตามหลัง Mythos 5

Anthropic ไม่ได้ขายราคาป้ายต่อ token ที่ถูกกว่า แต่ขาย**ต้นทุนที่ต่ำกว่าเพื่อจบงานประเภทเดียวกัน** นี่คือสนามแข่งของ lab ใหญ่ช่วงนี้

| Frontier-Bench v0.1 | ชนะโมเดลที่เทียบ; ~2× Opus 4.8 ด้วยต้นทุนต่องานที่ต่ำกว่า | งานวิศวกรรมระยะยาวแรงขึ้น *และ* ถูกขึ้นจริงไหม |

สรุป: **ราคา catalogue เท่าเดิม เส้นโค้ง “ผลผลิตที่มีประโยชน์ต่อหน่วยต้นทุน” ทางการขยับขึ้นชัด** หวังว่าจะเป็นจริงในการใช้งาน

## เสียงชุมชนช่วงแรก: คุ้มค่าคือธีมหลัก

วันหลังเปิดตัว บทสนทนาสาธารณะและวง builder **แบ่งฝ่าย**: บางคนว่าเทียบ Fable ได้ บางคนไม่เห็นด้วย จากประสบการณ์เรา ส่วนใหญ่ผูกกับ **agent stack และ harness ในตัว** ไม่ใช่แค่ base model

**ผู้สร้าง OpenResty 春哥 (Zhang Yichun)** ให้คะแนน Opus 5 สูง — ในกรอบประเมินของเขา อาจชนะ Fable ได้ด้วย **นักพัฒนาอิสระ Baye** มองตรงข้าม: การคิดของ Opus 5 ยังไม่ลึกและรอบด้านพอ ยังต้องใช้แรงจัดการมากขึ้น

ธีมที่โผล่ซ้ำ:

- **“ครึ่งราคาเทียบ Fable”** Fable 5 ~$10 / $50; Opus 5 ที่ $5 / $25 CursorBench max effort ห่าง peak ของ Fable ประมาณ 0.5% สำหรับงบทีม นี่คือการตั้งราคาใหม่ ไม่ใช่เปลี่ยนชื่อ
- **ลูป self-check แข็งขึ้น** เคสช่วงแรก: เปิด layout desktop/mobile จับสินค้าใต้ fold และปุ่ม checkout หลุดจอ แล้วแก้; หรือหา root cause ที่แพตช์ชุมชนพลาด
- **เถียงได้แต่ไม่ดื้อมืด** บางรายงาน refactor: โมเดลท้าทายดีไซน์แย่ ยึดจนชัดจุดเดียว แล้วเสนอทางประนีประนอม สำหรับ agent การมีดุลยพินิจดีกว่าเชื่อฟังมืด
- **เสียงเย็นกว่า** ยังควรรันบน harness ของคุณ Fast mode แลกความเร็วด้วยราคา 2×

สรุปฉันทามติ: **Opus 5 คือ “Opus ค่าเริ่มต้นประจำวัน” ที่น่าประเมินก่อนเป็นอันดับแรกตอนนี้**

## ความปลอดภัย

Anthropic จัด Opus 5 อยู่ในกลุ่มโมเดลที่**aligned ดีที่สุด**ชุดหนึ่ง: พฤติกรรมไม่พึงประสงค์ในการตรวจอัตโนมัติน้อยลง หลอกให้ใช้ผิดทางยากขึ้น

ด้าน cyber: *หา*ช่องโหว่แรงขึ้นมากและใกล้ Mythos 5; **การสร้าง exploit เต็มรูปยังอ่อนกว่ามาก** classifier ผ่อนกว่า Fable 5 คำขอที่ถูก flag อาจ fallback ไป Opus 4.8

สำหรับทีมผลิตภัณฑ์ส่วนใหญ่: “ช่วย audit เชิงรับ” โดยไม่กลายเป็นเครื่องมือโจมตีสำหรับทุกคน ในทางปฏิบัติควร**ตีความเจตนาผู้ใชผิดน้อยกว่า Fable 5** และใกล้การพัฒนาประจำวันมากกว่า

## สิ่งที่หมายถึงสำหรับนักพัฒนา

- **จาก Opus 4.8:** ราคา catalogue เท่าเดิม — เทียบ pass rate กับ tokens บน harness *ของคุณ* โดยทั่วไปไม่น่ามีปัญหา
- **เทียบ Fable 5:** ใช้ Fable เมื่อต้อง long-horizon สุดขีดและงบกับเกราะรับได้; งานส่วนใหญ่ Opus 5 คุ้มกว่า
- **เทียบ Sonnet 5:** ปริมาณงานและงาน pattern ใช้ Sonnet; debug / สถาปัตย์ / หลายไฟล์ใช้ Opus 5
- **effort และ Fast mode:** เริ่ม effort กลาง 春哥แนะนำอย่า max โดยไม่คิด — คิดมากเกินไปอาจ*ลด*คุณภาพ ส่วน Fast mode: ข้ามไปก่อน
- **skills เก่า / system prompt รัดเกิน:** โมเดล “มีท่าที” มากขึ้น — ล้าง rails เก่าอาจช่วย

## สิ่งที่หมายถึงสำหรับผู้ใช้ MuiRouter

MuiRouter ยึดไอเดียเดียว: API Key เดียว รูปแบบ integrate เดียว เปลี่ยนโมเดลเป็นการตั้งค่า

เราเพิ่ม `claude-opus-5` ในแคตตาล็อกที่ราคา $5 / $25 ตามที่ประกาศ (รวม cache) markup เท่า Claude รุ่นอื่น ชี้ `model` ไปที่ `claude-opus-5` (หรือเลือกใน Playground)

เช่นเคย อย่าตัด traffic โปรดักชันจนกว่าจะเช็ก end-to-end บทบาทของ unified gateway คือ: **โมเดลใหม่ ค่าเริ่มต้นใหม่ เส้นต้นทุนใหม่ โค้ดแอปแตะน้อยที่สุด**
