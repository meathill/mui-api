2026 年 7 月 24 日、Anthropic は Claude Opus 5 を公開しました。公式の位置づけは、生の能力では Fable/Mythos をやや下回るかもしれないが、価格はより親しみやすい、というものです。将来的には Fable の下で日常の実行役になる可能性があります。Anthropic はこれを**より能動的で、自分の作業を検証する**モデルと呼び、コーディングと知識作業で Claude Fable 5 に近づき、**価格は Fable 5 の半分**——Opus 4.8 と同じ $5 / $25（100 万トークンあたり）としています。

日常の開発者にとって、Anthropic の更新は毎回注目に値します。ここ数か月、Fable は強いが、高く、少なく、安全分類器に誤って刺されることも多く、Fable 出荷後は Opus 4.8 の「知能低下」という声が強まりました。Opus 5 はようやく希望を示します：**同価格で、能力が大きく上がる**。

MuiRouter はすでに `claude-opus-5` に対応しています。同じ API キー、同じ `/v1/chat/completions` と `/v1/messages`——モデル名を変えて試せます。

## Anthropic 更新サマリー

[Claude Opus 5 の発表](https://www.anthropic.com/news/claude-opus-5)と [System Card](https://www.anthropic.com/claude-opus-5-system-card) より：

- モデル ID：`claude-opus-5`。API、Claude Code、Claude Platform で利用可能。
- **Claude Max の新しいデフォルト**であり、Claude Pro で現在使える最強モデル。
- 価格は Opus 4.8 と同じ：入力 $5 / 1M tokens、出力 $25 / 1M tokens。
- 任意の **Fast mode**：デフォルトの約 2.5 倍速、価格は基本の 2 倍。
- 焦点：長時間エージェント、ソフトウェア工学、知識作業、能動的な検証と反復。Mythos のようにサイバー攻撃寄りではないため、「パートナー限定」リリースは不要。

Anthropic は明示しています。サイバーセキュリティのエクスプロイト面では、Opus 5 は Mythos 5 より**意図的に**後ろに置かれています。

## ベンチマークとコスト：完了タスクあたりのコストを下げる

Anthropic が売っているのはトークン単価の値下げではありません。**同じ種類の仕事を終わらせるコストの低下**です。それが最近の大手ラボの市場競争の焦点でもあります。

| 領域 | Anthropic / パートナーの位置づけ | なぜ重要か |
| --- | --- | --- |
| Frontier-Bench v0.1 | 比較モデルを上回り、約 2× Opus 4.8 をより低いタスクコストで | 長時間エンジニアリングが本当に強く *かつ* 安いか |
| CursorBench 3.2（max effort） | Fable 5 のピークから約 0.5% 以内、タスクコストは約半分 | 日常の IDE / エージェントコーディング |
| ARC-AGI 3 | 次点の約 3 倍 | 新規問題、非常規な推論 |
| Zapier AutomationBench | 同コストで次点の約 1.5 倍の通過率；最低 effort でもしばしば首位 | ビジネス自動化の end-to-end |
| OSWorld 2.0 | 任意コスト点で最良；Fable 5 のピークを約 1/3 コストで超える | コンピュータ利用 / デスクトップエージェント |
| GDPval-AA など知識作業 | 新 SOTA（Fable 帯で競争） | レポート、調査、専門ドキュメント |

要するに：**定価は同じで、公式の「コスト単位あたりの有効出力」曲線は明確に上へ**。実践でもそうであることを望みます。

## コミュニティ初期反応：コスパが主旋律

公開翌日、公開議論とビルダー界隈は**賛否が分かれる**：Fable 並みと言う人もいれば、反対の人もいます。私たちの経験では、それはベースモデルだけでなく、**エージェント構成とその内蔵 harness** に左右されることが多いです。

**OpenResty の作者 春哥（Zhang Yichun）** は Opus 5 を高く評価し、独自の評価枠では Fable を超えることさえあると言います。**独立開発者 Baye** は逆で、Opus 5 の思考は深くも網羅的でもなく、管理により多くの労力が要る、としています。

繰り返し出るテーマ：

- **「Fable の半額。」** Fable 5 は約 $10 / $50；Opus 5 は $5 / $25。CursorBench max effort は Fable ピークから約 0.5%。チーム予算にとっては、名前替えではなく再価格付けのシグナルです。
- **自己チェックの強化。** 初期例：デスクトップとモバイルを開き、折り目下の商品や画面外のチェックアウトボタンを見つけて修正する；コミュニティパッチが逃した根本原因を見つける。
- **盲目ではない反論。** 一部のリファクタ報告では、悪い設計に異議を唱え、一点まで議論を絞り、妥協案を出す、とあります。エージェントでは、盲目の服従より判断が人を省きます。
- **冷静な声。** *自分の* harness で測り直すこと。Fast mode は速度の代わりに定価 2 倍。

要約すると：**Opus 5 は現在、最初に評価する価値がある「日常デフォルトの Opus」** です。

## 価格一覧

| モデル | Input | Output |
| --- | ---: | ---: |
| `claude-fable-5` | $10 / 1M tokens | $50 / 1M tokens |
| `claude-opus-5` | $5 / 1M tokens | $25 / 1M tokens |
| `claude-opus-4-8` | $5 / 1M tokens | $25 / 1M tokens |
| `claude-sonnet-5`（導入価格、2026-08-31 まで） | $2 / 1M tokens | $10 / 1M tokens |
| `claude-sonnet-5`（標準価格、2026-09-01 から） | $3 / 1M tokens | $15 / 1M tokens |

Anthropic 標準の prompt caching は引き続き有効です。Sonnet 5 のときと同じく、**完了タスクの請求で判断**し、ステッカー価格だけに頼らないこと。

Fast mode：約 2.5 倍速、基本の 2 倍価格、対話的コーディング向け；長時間バッチはまずデフォルト帯で。

## 安全性とセーフガード

Anthropic は Opus 5 をこれまでで**最もアライメントの良い**モデルの一つとしています。自動行動監査での望ましくない行動が少なく、悪用へ騙されにくく、取り返しのつかない無鉄砲な行動も少ない、とのことです。

サイバー面：脆弱性の*発見*は大幅に強く Mythos 5 に近づきますが、**完全なエクスプロイト開発は依然としてかなり弱い**。分類器は Fable 5 より緩く、フラグされたリクエストは Opus 4.8 にフォールバックできます。

多くの製品チームにとって、それは「防御的な監査を手伝える」一方で、誰でも使える攻撃ツールにはならない、という意味です。実務上は Fable 5 より**ユーザー意図の誤判定が少なく**、日常の開発に近いはずです。

## 開発者にとっての意味

- **Opus 4.8 からの移行：** 定価は同じ——*自分の*ハーネスで通過率とトークンを比較。一般には問題になりにくい。
- **Fable 5 との比較：** 極端な長時間作業で予算とガードレールが許すなら Fable；大半のコーディングと知識作業は Opus 5 の方がお得。
- **Sonnet 5 との比較：** 量と定型は Sonnet；判断の重いデバッグ・設計・複数ファイルは Opus 5。
- **effort と Fast mode：** 中程度の effort から。春哥は無思考に max するなと勧める——考えすぎはかえって質を*下げる*。Fast mode は今のところパスでよい。
- **古い skills / 過度に縛った system prompt：** モデルはより「意見が強い」——古いレールを掃除すると結果がきれいになることがある。

## MuiRouter ユーザーにとっての意味

MuiRouter の考え方はシンプルです。1 つの API キー、1 つの統合スタイル、モデル切替は設定変更。

`claude-opus-5` を公開価格 $5 / $25（キャッシュ込み）でカタログに追加し、他の Claude と同じ markup です。`model` を `claude-opus-5` に（または Playground で選択）。

いつもの通り、本番切替は自分のアカウントでの end-to-end 確認後に。統一ゲートウェイの役割は：**新モデル、新デフォルト、新コスト曲線、アプリコードはできるだけ触らない**。

## まとめ

Claude Opus 5 は、堅実な日常アップデートに加え、**同価格での世代アップ**です。公式数字と初期コミュニティの反応は、より高いコーディング／知識の天井と、タスクあたりのより低いコストを指しています。春哥の評価は、能力ジャンプに注目するもう一つの理由です。

まだ Opus 4.8 なら、早めのアップグレードをおすすめします。Fable 5 の価格やガードレールで迷っていたなら、Opus 5 がより適切なデフォルトツールである可能性が高いです。
