## Built for Long-Running Agents

Grok 4.6 builds on Grok 4.5 with a particular focus on sustained work: researching a topic, analyzing information, working across a codebase, or turning an idea into a polished application. Key points:

- **Frontier agentic intelligence**: matches GPT-5.6 Sol on the Artificial Analysis Intelligence Index (61 vs 61), well ahead of Grok 4.5 High (56).
- **Stronger long-horizon behavior**: on longer trajectories the model increasingly tests and verifies its own work before moving on.
- **Better first passes on visual and interactive projects**: it establishes structure and a visual language for an application in one pass, making it especially useful for iterating from a rough idea to a working first version.
