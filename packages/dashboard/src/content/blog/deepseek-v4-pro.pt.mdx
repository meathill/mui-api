A DeepSeek publicou a versão estável do seu modelo principal — **DeepSeek-V4-Pro-0813** (`deepseek-v4-pro`) — completando a família V4 iniciada com a prévia de abril. O lançamento oficial mantém a arquitetura **MoE de 1,6 trilhão de parâmetros no total / 49 bilhões ativos** e a janela de contexto de 1M característica da família, com saída máxima de 384K tokens.

O `deepseek-v4-pro` já está disponível no MuiRouter. Com uma única chave de API e uma simples mudança de nome de modelo, você pode chamá-lo pelo endpoint padrão compatível com OpenAI (`/v1/chat/completions`).

## Principais recursos

| Recurso | DeepSeek V4 Pro |
| --- | --- |
| **Arquitetura** | MoE 1,6T parâmetros no total, 49B ativos por token |
| **Janela de contexto** | 1.048.576 tokens (1M) |
| **Saída máxima** | até 384K tokens |
| **Modo de raciocínio** | sem raciocínio / raciocínio (padrão) |
| **Recursos** | JSON Output, chamadas de ferramentas, API Responses, API Anthropic, prefixo de chat, FIM (somente sem raciocínio) |

## Preços oficiais e cobrança MuiRouter

Preços oficiais da API DeepSeek:

| Tipo de token | Preço (por 1M tokens) |
| --- | ---: |
| **Entrada (falha de cache)** | **US$ 0,435** |
| **Entrada (acerto de cache)** | **US$ 0,003625** |
| **Saída** | **US$ 0,87** |

No MuiRouter, o `deepseek-v4-pro` aplica nossa margem padrão de 1,2: **US$ 0,522 / US$ 0,00435 / US$ 1,044 por milhão de tokens** (entrada, entrada em cache, saída). Observe que a DeepSeek anunciou oficialmente um aumento geral de preços em um futuro próximo — um bom motivo para garantir as tarifas atuais.

## Conclusão

O modelo principal de pesos abertos da família DeepSeek V4 já está disponível em versão estável: contexto de 1M, modos de raciocínio e sem raciocínio, e custos de prompt caching muito agressivos por uma fração do preço de modelos fechados comparáveis. Experimente hoje no Playground do MuiRouter, no seu agente de terminal ou pela API compatível com OpenAI: cobrança transparente por uso, sem assinatura mensal.
