DeepSeek はフラッグシップの正式版 — **DeepSeek-V4-Pro-0813**（`deepseek-v4-pro`）— を公開し、4月のプレビューで始まった V4 ファミリーが完成しました。正式版は **1.6T 総パラメータ / 49B アクティブ** の MoE アーキテクチャと、ファミリー共通の 1M コンテキストウィンドウを維持しつつ、最大出力は 384K tokens に拡大しています。

`deepseek-v4-pro` は MuiRouter ですぐに利用できます。1つの API Key とモデル名の変更だけで、標準の OpenAI 互換エンドポイント（`/v1/chat/completions`）から呼び出せます。

## 主な特徴

| 項目 | DeepSeek V4 Pro |
| --- | --- |
| **アーキテクチャ** | MoE 1.6T 総パラメータ、トークンごとに 49B アクティブ |
| **コンテキストウィンドウ** | 1,048,576 tokens (1M) |
| **最大出力** | 最大 384K tokens |
| **思考モード** | 非思考 / 思考（デフォルト） |
| **対応機能** | JSON Output、Tool Calls、Responses API、Anthropic API、Chat Prefix、FIM（非思考モードのみ） |

## 公式料金と MuiRouter の請求

DeepSeek 公式 API 料金：

| トークンタイプ | 料金（1M tokens あたり） |
| --- | ---: |
| **入力（Cache Miss）** | **$0.435** |
| **入力（Cache Hit）** | **$0.003625** |
| **出力** | **$0.87** |

MuiRouter では `deepseek-v4-pro` に標準の 1.2 マークアップを適用します：**$0.522 / $0.00435 / $1.044（1M tokens あたり：入力、キャッシュ入力、出力）**。なお、DeepSeek は近い将来 API 価格を全体的に引き上げることを正式に発表しています — 今のうちに価格を固定しておくのが賢明です。

## まとめ

DeepSeek V4 ファミリーのオープンウェイト・フラッグシップが正式版で登場：1M コンテキスト、思考/非思考の両モード、そして同クラスのクローズドモデルを大きく下回る価格での超低コスト Prompt Caching。MuiRouter の Playground、ターミナル AI Agent、OpenAI 互換 API から今すぐお試しください。月額なしの透明な従量課金です。
