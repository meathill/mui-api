DeepSeek ha publicado la versión estable de su modelo insignia — **DeepSeek-V4-Pro-0813** (`deepseek-v4-pro`) — completando la familia V4 iniciada con la vista previa de abril. El lanzamiento oficial conserva la arquitectura **MoE de 1,6 billones de parámetros en total / 49 mil millones activos** y la característica ventana de contexto de 1M de la familia, con una salida máxima de 384K tokens.

`deepseek-v4-pro` ya está disponible en MuiRouter. Con una sola clave API y un simple cambio de nombre de modelo, puedes llamarlo a través del endpoint estándar compatible con OpenAI (`/v1/chat/completions`).

## Puntos clave

| Característica | DeepSeek V4 Pro |
| --- | --- |
| **Arquitectura** | MoE 1,6T parámetros en total, 49B activos por token |
| **Ventana de contexto** | 1 048 576 tokens (1M) |
| **Salida máxima** | hasta 384K tokens |
| **Modo de razonamiento** | sin razonamiento / razonamiento (por defecto) |
| **Capacidades** | JSON Output, llamadas de herramientas, API Responses, API Anthropic, prefijo de chat, FIM (solo sin razonamiento) |

## Precios oficiales y facturación MuiRouter

Precios oficiales de la API de DeepSeek:

| Tipo de token | Precio (por 1M tokens) |
| --- | ---: |

En MuiRouter, `deepseek-v4-pro` aplica nuestro margen estándar de 1,2: **0,522 $ / 0,00435 $ / 1,044 $ por millón de tokens** (entrada, entrada en caché, salida). Ten en cuenta que DeepSeek ha anunciado oficialmente una subida general de precios en un futuro próximo: una buena razón para asegurar las tarifas actuales.

El modelo insignia de pesos abiertos de la familia DeepSeek V4 ya está disponible en versión estable: contexto de 1M, modos de razonamiento y no razonamiento, y costes de prompt caching muy agresivos por una fracción del precio de los modelos cerrados comparables.
