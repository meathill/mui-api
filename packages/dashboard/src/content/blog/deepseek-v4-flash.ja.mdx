2026年7月31日、DeepSeek は新世代の軽量フラッグシップモデル **DeepSeek V4 Flash**（バージョン `DeepSeek-V4-Flash-0731`）を正式リリースしました。DeepSeek V4 シリーズの中で高スループットと超高速レスポンスを追求した MoE 構成モデルであり、**総パラメータ 2840 億 / アクティブ 130 億** の洗練された設計により、Agent コーディング、コード補完、長文推論タスクで圧倒的な性能を発揮します。

前回の DeepSeek V4 リリースからわずか1ヶ月余りで、大きなアーキテクチャ変更なしに推論能力（特に複雑タスクの処理能力）が大幅向上し、ベンチマークによっては上位モデルの DeepSeek V4 Pro をも凌駕する驚くべき進化を遂げました。これほどの低価格で提供されることは驚嘆に値します。AI 発展を資金面で支えた A 株投資家の皆様にも感謝いたします。

MuiRouter では `deepseek-v4-flash` への対応を完了しました。ターミナル AI Agent での利用はもちろん、標準の OpenAI 互換 API (`/v1/chat/completions`) 経由でも、単一の API Key とモデル名の変更だけで、1M 入力 Token あたりわずか $0.14 という圧倒的コスパでご利用いただけます。

## DeepSeek V4 Flash の主な特徴

公式スペックおよび検証データによる主な特徴は以下の通りです：

| 項目 | DeepSeek V4 Flash |
| --- | --- |
| **アーキテクチャ** | 284B 総パラメータ MoE、トークンごとに 13B 専門家パラメータをアクティブ化 |
| **コンテキストウィンドウ** | 1,048,576 tokens (1M) |
| **長文アテンション** | Compressed Sparse Attention (CSA) と Heavily Compressed Attention (HCA) のハイブリッド |
| **機能サポート** | 思考モード（Reasoning Content）、Tool Call、JSON Mode & Structured Output |
| **オープンウェイト** | オープン重み（GGUF / Ollama ローカル実行対応）と公式 API の両立 |
| **公式 API 料金** | 入力 $0.14 / 1M tokens (Cache ヒット時 $0.0028)；出力 $0.28 / 1M tokens |

### 1. 1M コンテキストと驚異的な Prompt Caching コスト

DeepSeek V4 Flash は最大 1M (1,048,576) Token の長文コンテキストをネイティブサポートしています。大規模リポジトリの解析や長文コードセッションにおいて、公式の Prompt Caching と組み合わせることで、キャッシュヒット時の入力トークン料金はわずか **$0.0028 / 1M tokens**（通常料金のわずか 2%）まで抑えられます。

これにより、ターミナル Agent がコードベース全体を繰り返し読み込む際の日常的な Token コストを極限まで削減できます。

### 2. Agent および長周期コーディングへの最適化

`DeepSeek-V4-Flash-0731` では、最新の再ポストトレーニング（Re-post-training）により Agentic ワークフロー能力が大幅に強化されました。高スループット・低遅延の出力により、Agent が「要件分析 -> 計画 -> コード記述 -> ターミナル実行 -> 自動エラー修正」のループを高速かつ滑らかに実行します。

## 公式 API 料金と MuiRouter の請求

DeepSeek 公式 API 料金は以下の通りです：

| トークンタイプ | 公式料金（1M tokens あたり） |
| --- | ---: |
| **未ヒット入力 (Cache Miss)** | **$0.14** |
| **ヒット入力 (Cache Hit)** | **$0.0028** |
| **出力 (Output / Reasoning)** | **$0.28** |

MuiRouter では、月額サブスクリプション不要の実利用量に基づく透明性の高い従量課金を提供します。

DeepSeek V4 Flash の登場により、高性能オープンモデルのレスポンス速度とコストの限界が刷新されました。MuiRouter と組み合わせることで、開発者は極めて魅力的な価格で最先端の Agent コーディング能力を手に入れることができます。
