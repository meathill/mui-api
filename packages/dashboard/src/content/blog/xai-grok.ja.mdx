2026 年 7 月 8 日、xAI は Grok 4.5 を公開した。新しい flagship model であり、Cursor（前月に xAI が 600 億ドルで買収合意した AI coding editor）と並行して train され、Claude Opus 4.8 に直接ぶつける位置づけだ。Elon Musk はこれを「Opus-class model だが、より速く、token 効率が高く、コストが低い」と表現した。Release day としては大きな claim であり、それは Grok line 全体の改善の上に乗っている。より大きな context window、native video input、より高速な Imagine video stack、そして新しい distribution channel、つまり Grok が Cloudflare AI Gateway から直接利用可能になったことだ。

この最後の部分が、私たちを素早く動かした。今日、`grok-4.5`、`grok-4.3`、`grok-imagine-image` を MuiRouter catalog に追加した。すでに OpenAI、Anthropic、Gemini で使っているのと同じ `/v1/chat/completions` と `/v1/images/generations` endpoint から呼び出せる。

## xAI が公開したもの：Grok 4.5

Grok 4.5 は xAI の 1.5 兆 parameters V9 foundation 上に構築され、現在 Grok Build の default model になっている。価格は input token 100 万あたり $2、output token 100 万あたり $6 で、およそ 80 tokens/sec で動作する。

xAI が launch day に公開した benchmark と Claude Opus 4.8 の比較は次の通り。

| Benchmark | Grok 4.5 | Opus 4.8 (max) |
| --- | ---: | ---: |
| SWE Marathon (pass@1) | 29.0% | 26.0% |
| Terminal Bench 2.1 | 83.3% | 78.9% |
| SWE-Bench Pro (resolve rate) | 64.7% | 69.2% |

見るべき数字は勝ち負けの列ではなく、token efficiency だ。SWE-Bench Pro で xAI は、Grok 4.5 が平均 15,954 output tokens でタスクを解決したのに対し、同じ benchmark で Opus 4.8 は 67,020 tokens を使ったと報告している。4.2x の差だ。これが実 workload でも成立するなら、token 単価が高いことは必ずしも完了タスクあたりのコストが高いことを意味しない。

一つ明確に注意しておきたい。これは xAI 自身の launch page にある self-reported numbers であり、まだ independent verification はない。同日 release では普通のことだ。Vendor の claim として読み、重要な判断に使うなら自分の workload で確認してからにしてほしい。

## Lineup の残り

Grok 4.5 だけが最近の動きではない。`grok-4.3` は、より大きな context option として catalog に残っており、1M-token window と native video input をサポートし、PDF、spreadsheet、slide deck を直接生成できる。Grok Imagine は version 1.5 へ上がり、native synchronized audio 付きで 720p / 24fps の video を生成し、release 時に third-party image-to-video leaderboard の上位に上がった。xAI はさらに 21 の multilingual voices と、25 言語対応の generally available Speech-to-Text API も出した。これらは今週の headline ではないが、Grok 4.5 が立っている土台だ。

## MuiRouter に追加したもの

まずは三つのモデルだ。

- **`grok-4.5`** — xAI の新 flagship。Agentic あるいは coding-heavy なものでは最初に試す価値がある。
- **`grok-4.3`** — 1M context option。4.5 の 500K window では足りないときに有用。
- **`grok-imagine-image`** — `gpt-image-2` で使っているのと同じ `/v1/images/generations` shape による text-to-image generation。

アクセスは MuiRouter 上の OpenAI や Gemini と同じく Cloudflare AI Gateway 経由だ。利用者側で別の xAI account を作ったり key を管理したりする必要はない。現在の per-token pricing は [pricing page](/pricing) にあり、実際に charge する内容と同期している。Blog post に固定された数字より、そのページを見てほしい。

Video generation (`grok-imagine-video`) は今回の release には含めていない。これは async な job-based API で、request を submit し、完了まで poll する形だ。今日私たちが route している他のすべてのモデルとは integration shape が違う。Roadmap には入っており、ship したら改めて書く。

## 開発者にとっての意味

- Grok 4.5 は、実績あるモデルに対する release day claim であり、確定した結論ではない。Benchmark table を purchase decision として扱う前に、自分の agentic/coding workload で試してほしい。
- Token efficiency が自分の prompt でも成立するなら、token 単価が高くても cost math は変わる。直接測る価値がある。
- `grok-4.3` の 1M-token window は、小さい context に入れるために chunk していた作業で試す価値がある。
- `grok-imagine-image` は、すでに `/v1/images/generations` を中心に作られた workflow にそのまま入る。

## MuiRouter ユーザーにとっての意味

新しい provider を追加するたびに話は同じだ。Integration は変わらない。一つの API key、一つの request shape、そして model catalog が裏側で増えていく。今日 Grok を追加したこと、しかも新 flagship が出たその日に追加できたことは、`grok-4.5` を今すぐ既存のモデルと比較できるという意味だ。同じ billing、同じ rate limits、同じ account。より合うかを調べるためだけに二つ目の integration を作る必要はない。

## まとめ

Grok 4.5 は初日から大きな claim を掲げている。Cursor の coding DNA を持ち、Anthropic の frontier tier と直接競うように pricing と benchmark を置いた Opus-class model だ。その claim が independent testing に耐えるかはまだ分からない。しかし、今では一つの MuiRouter API key で、すでに使っている他のモデルと並べて試せる。答えを見つけるコストは、model name を一つ変えるだけだ。
