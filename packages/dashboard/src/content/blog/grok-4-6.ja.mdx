2026年8月12日、xAI は**Grok 4.6** を発表しました。長期実行エージェントと、より意欲的なインタラクティブ・ビジュアル作業に特化した新しい最前線モデルです。

`grok-4.6` は MuiRouter ですぐに利用できます。1つの API Key とモデル名の変更だけで、標準の OpenAI 互換エンドポイント（`/v1/chat/completions`）から呼び出せます。

## 長期エージェントのために生まれたモデル

Grok 4.6 は Grok 4.5 をベースに、持続的な作業を重視しています：トピックの調査、情報の分析、コードベース横断の作業、アイデアを洗練されたアプリケーションに仕上げることなどです。主なポイント：

- **エージェント性能は最前線レベル**：Artificial Analysis インテリジェンス指数で GPT-5.6 Sol に並ぶ 61 点（61 対 61）。Grok 4.5 High（56）を大きく引き離します。
- **長いタスクでの自己検証**：長いトラジェクトリでは、モデルは次のステップに進む前に自身の作業をテスト・検証するようになります。
- **ビジュアル・インタラクティブプロジェクトの初回品質が向上**：アプリの構造とビジュアル言語を 1 パスで確立し、荒削りなアイデアから動くファーストバージョンへ最短で進めます。

## 価格

Grok 4.6 の価格は 4.5 と同一：**入力 $2 / 1M tokens、出力 $6 / 1M tokens**（2 倍の価格の高速版もあり）。xAI API、Cursor、Grok Build、および OpenRouter、Vercel、Cloudflare などのパートナー経由で利用できます。

MuiRouter では `grok-4.6` を公式価格に 1.05 のマークアップを加えて課金します：**$2.10 / $6.30（1M tokens あたり）**。
