DeepSeek ปล่อยเวอร์ชันเต็มของโมเดลเรือธง — **DeepSeek-V4-Pro-0813** (`deepseek-v4-pro`) — ทำให้ตระกูล V4 ที่เริ่มจาก Preview เมื่อเดือนเมษายนครบสมบูรณ์ เวอร์ชันเต็มอย่างเป็นทางการยังคงสถาปัตยกรรม **MoE 1.6T พารามิเตอร์รวม / 49B แอคทีฟ** และหน้าต่าง context 1M อันเป็นเอกลักษณ์ของตระกูล พร้อม output สูงสุด 384K tokens

`deepseek-v4-pro` พร้อมใช้งานบน MuiRouter แล้ว ด้วย API Key เพียงชุดเดียวและแค่เปลี่ยนชื่อโมเดล คุณก็สามารถเรียกใช้ผ่าน endpoint ที่เข้ากันได้กับ OpenAI มาตรฐาน (`/v1/chat/completions`)

## จุดเด่นหลัก

| รายการ | DeepSeek V4 Pro |
| --- | --- |

## ราคาอย่างเป็นทางการและการคิดเงิน MuiRouter

ราคา API อย่างเป็นทางการของ DeepSeek:

| ประเภท Token | ราคา (ต่อ 1M tokens) |
| --- | ---: |
| **Input (Cache Miss)** | **$0.435** |
| **Input (Cache Hit)** | **$0.003625** |
| **Output** | **$0.87** |

บน MuiRouter `deepseek-v4-pro` คิด markup มาตรฐาน 1.2: **$0.522 / $0.00435 / $1.044 ต่อ 1M tokens** (input, input แบบ cache, output) หมายเหตุ: DeepSeek ประกาศอย่างเป็นทางการแล้วว่าจะปรับขึ้นราคา API โดยรวมในเร็วๆ นี้ — เป็นเหตุผลดีๆ ในการล็อกราคาปัจจุบันไว้

## สรุป

โมเดลเรือธงโอเพนเวตของตระกูล DeepSeek V4 พร้อมใช้งานเวอร์ชันเต็มแล้ว: context 1M, โหมดคิด/ไม่คิด และต้นทุน Prompt Caching ที่ต่ำมาก ในราคาเพียงเศษเสี้ยวของโมเดลปิดระดับเดียวกัน ลองใช้เลยวันนี้ทั้งใน Playground ของ MuiRouter, Agent ในเทอร์มินัลของคุณ หรือผ่าน API ที่เข้ากันได้กับ OpenAI — คิดเงินตามการใช้งานจริง โปร่งใส ไม่มีค่าสมาชิกรายเดือน
