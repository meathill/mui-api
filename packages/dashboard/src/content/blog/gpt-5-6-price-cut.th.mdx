เมื่อวันที่ 30 กรกฎาคม 2026 OpenAI ได้ประกาศลดราคาโมเดลระดับกลางและระดับเริ่มต้นในตระกูล GPT-5.6 อย่างเหนือความคาดหมาย ได้แก่ **GPT-5.6 Luna** และ **GPT-5.6 Terra** ซึ่งเกิดขึ้นเพียง 3 สัปดาห์หลังจากเปิดตัว GPT-5.6 อย่างเป็นทางการ

GPT-5.6 เปิดตัวตามหลัง Fable ด้วยราคาที่คงมาตรฐานเดิมและประสิทธิภาพที่ไม่ได้รู้สึกว่าดีขึ้นอย่างก้าวกระโดด ทำให้ชุมชนนักพัฒนาวิพากษ์วิจารณ์ถึงความคุ้มค่า บางส่วนถึงกับให้รีวิวในแง่ลบเนื่องจากมักตกหลุมพรางของการคิดซับซ้อนเกินไป (Overthinking) อย่างไรก็ตาม การปรับลดราคาครั้งใหญ่อย่างกะทันหันนี้เปรียบเสมือนระเบิดที่ลงกลางวงการนักพัฒนา และได้รับการตอบรับในเชิงบวกอย่างท่วมท้น

## ภาพรวมรายละเอียดการปรับลดราคา

ตามประกาศอย่างเป็นทางการของ OpenAI ราคา API ได้รับการอัปเดตดังนี้:

| โมเดล | ราคาเดิม (ต่อ 1M tokens) | ราคาใหม่ (ต่อ 1M tokens) | สัดส่วนการลดราคา |
| --- | --- | --- | ---: |
| **GPT-5.6 Luna** | ข้อมูลเข้า $1.00 / ข้อมูลออก $6.00 | **ข้อมูลเข้า $0.20 / ข้อมูลออก $1.20** | **-80%** |
| **GPT-5.6 Terra** | ข้อมูลเข้า $2.50 / ข้อมูลออก $15.00 | **ข้อมูลเข้า $2.00 / ข้อมูลออก $12.00** | **-20%** |
| **GPT-5.6 Sol** | ข้อมูลเข้า $5.00 / ข้อมูลออก $30.00 | ข้อมูลเข้า $5.00 / ข้อมูลออก $30.00 (ไม่เปลี่ยนแปลง) | 0% |

หมายเหตุ:

- ราคาพื้นฐานของ Sol ยังคงเดิม แต่มีการเปิดตัว **Fast Mode** ซึ่งให้ความเร็วในการสร้างคำตอบสูงสุด 2.5 เท่า ในอัตราค่าบริการ 2 เท่าของราคาพื้นฐาน
- Cached Input ยังคงได้รับส่วนลด 90% (คิดเพียง 10% ของราคาพื้นฐาน)
- การลดราคานี้ปรับใช้กับโควต้าการสมัครสมาชิก ChatGPT Work และ Codex โดยอัตโนมัติ

## สรุปมุมมองสำคัญจากชุมชนนักพัฒนา

จากการรวบรวมการพูดคุยบน X (Twitter), Reddit และ Hacker News มุมมองของชุมชนสรุปได้เป็น 3 ประเด็นหลัก:

### 1. "โมเดลระดับเริ่มต้น + การคิดระดับสูง" ทางเลือกใหม่ที่คุ้มค่า
[นักพัฒนา @rafaquint ได้คาดการณ์จากผลทดสอบ DeepSWE Benchmark](https://x.com/rafaquint/status/2082942652811485549) ว่าเมื่อนำระดับความลึกในการคิด (Reasoning Effort) เข้ามาพิจารณา Luna Max ที่ลดราคาแล้วใช้ค่าใช้จ่ายเพียง 1/3 แต่มีแนวโน้มที่จะให้ผลลัพธ์เหนือกว่า Sol Medium
กระแสของ "โมเดลเริ่มต้น + ใส่แรงคิดเต็มที่" ทำให้นักพัฒนารู้สึกว่าไม่จำเป็นต้องใช้โมเดลราคาสูงเสมอไป และ Luna Max เป็นตัวเลือกที่น่าลองอย่างยิ่งสำหรับงานเขียนโค้ดและระบบอัตโนมัติของ Agent

### 2. มุ่งเน้นต้นทุนต่อภารกิจ (Cost-per-Task) และระบบกำหนดเส้นทางโมเดลแบบหลายระดับ
ยุคสมัยของการบริโภค Token แบบไม่จำกัดได้สิ้นสุดลงแล้ว องค์กรและนักพัฒนายอมรับและมุ่งเน้นที่ "ต้นทุนรวมในการทำภารกิจสำเร็จ" โมเดล Luna ($0.20/$1.20) และ Terra ($2.00/$12.00) จึงกลายเป็นลำดับขั้นที่สมบูรณ์แบบ:
- **Luna** รับหน้าที่ประมวลผลข้อมูลจำนวนมาก วิเคราะห์ Log และลองใหม่ด้วยต้นทุนต่ำ
- **Terra** รับหน้าที่เขียนโค้ดและตรวจทานโค้ด (Review)
- งานที่ท้าทายและยากที่สุดเท่านั้นที่จะถูกส่งต่อไปยัง **Sol**

### 3. โมเดล Open Source แบบโฮสต์เอง (vLLM / Ollama) สูญเสียความคุ้มค่า
นักพัฒนาอิสระหลายรายระบุว่า การเช่า GPU เพื่อรันโมเดล Open Source ผ่าน vLLM เพื่อประหยัดเงิน เมื่อบวกค่าเช่าเครื่อง การบำรุงรักษา และข้อจำกัดเรื่องการทำงานพร้อมกันแล้ว ความคุ้มค่าสูญเสียไปเมื่อเทียบกับราคา $0.20/1M ของ Luna นักพัฒนาและทีมขนาดเล็กจำนวนมากจึงน่าจะกลับมาใช้ Commercial API

## มุมมองของเรา: การโต้ตอบ Open Source และการจัดทัพโมเดลระดับกลาง-เล็กใหม่

ทำไมชุมชนถึงตอบรับการลดราคา Luna และ Terra อย่างล้นหลาม? เบื้องหลังราคาที่ดึงดูดใจนี้คือการเปลี่ยนแปลงเชิงโครงสร้างของการแข่งขันในตลาด AI

### 1. วิกฤตคุณภาพของคู่แข่ง
หากพิจารณาโมเดลแบบปิดในเชิงพาณิชย์ ตลาดโมเดลขนาดกลางและเล็กกำลังเผชิญวิกฤตคุณภาพอย่างหนัก ตัวอย่างเช่น Google ที่เปิดตัว **Gemini 3.6 Flash ซึ่งคุณภาพแย่และถอยหลังไปกว่าหนึ่งปี** ส่วนข่าวลือเรื่อง **Gemini 3.6 Pro** ที่ยังไม่เปิดตัว ก็น่าจะมาจากปัญหาคุณภาพที่ยังตกต่ำ ในสภาพแวดล้อมเช่นนี้ นักพัฒนาจึงแทบไม่เหลือตัวเลือกโมเดลขนาดเล็กที่มีคุ้มค่า

### 2. บริบท 1M Tokens + การปรับแต่งเฉพาะสำหรับ AI Agent
การมองว่า Luna เป็นเพียง "โมเดลลดสเปก" ถือเป็นความเข้าใจผิด:
- **ขนาดบริบท 1M Tokens**: ทั้ง Luna และ Terra รองรับ Context Window ขนาด 1 ล้าน Tokens แบบเนทีฟ ซึ่งเป็นสิ่งที่โครงสร้างพื้นฐานแบบโฮสต์เอง (เช่น คลัสเตอร์ vLLM/Ollama) ทำได้ยาก
- **ปรับแต่งเพื่อ AI Agent โดยเฉพาะ**: Luna เป็นโมเดลที่ OpenAI กลั่นกรอง (Distill) และปรับแต่งจากโมเดลเรือธง ปรับปรุงการเรียกใช้เครื่องมือ (Tool Calling) การทำตามคำสั่ง และการจัดลำดับ Workflow เหมาะอย่างยิ่งที่จะเป็นสมองควบคุมงานประจำวันของ AI Agent

### 3. ก้าวสำคัญของ OpenAI ในการรับมือกับโมเดล Open Source จากจีน
ในช่วงครึ่งปีที่ผ่านมา โมเดล Open Source จากประเทศจีน (นำโดย DeepSeek และอื่นๆ) แย่งชิงส่วนแบ่งตลาดอย่างรวดเร็วด้วยความคุ้มค่าและประสิทธิภาพการคิดวิเคราะห์ที่สูง

เราเชื่อว่าการที่ OpenAI ลดราคา Luna ลง 80% เหลือ $0.20/$1.20 เป็น **กลยุทธ์สำคัญของ OpenAI ในการรับมือการท้าทายจากโมเดล Open Source ของจีน** ด้วยการผสมผสานราคาที่ดึงดูด บริบท 1M แบบเนทีฟ และความเสถียรระดับ Enterprise Cloud เพื่อปิดโอกาสการทดแทนของโมเดล Open Source ในงานระดับเล็กและกลาง
