เมื่อวันที่ 12 สิงหาคม 2026 xAI เปิดตัว **Grok 4.6** — โมเดลระดับแนวหน้าใหม่ที่ให้ความสำคัญกับงาน Agent ระยะยาวและงาน Visual/Interactive ที่ทะเยอทะยานมากขึ้น

`grok-4.6` พร้อมใช้งานบน MuiRouter แล้ว ด้วย API Key เพียงชุดเดียวและแค่เปลี่ยนชื่อโมเดล คุณก็สามารถเรียกใช้ผ่าน endpoint ที่เข้ากันได้กับ OpenAI มาตรฐาน (`/v1/chat/completions`)

## สร้างมาเพื่องาน Agent ระยะยาว

Grok 4.6 ต่อยอดจาก Grok 4.5 โดยให้ความสำคัญกับงานที่ต้องทำต่อเนื่องยาวนาน: ค้นคว้าหัวข้อ วิเคราะห์ข้อมูล ทำงานข้าม codebase หรือเปลี่ยนไอเดียให้เป็นแอปพลิเคชันที่สมบูรณ์ ประเด็นสำคัญ:

- **ความฉลาดระดับแนวหน้าด้าน Agent**: ทำคะแนนเท่ากับ GPT-5.6 Sol บน Artificial Analysis Intelligence Index (61 ต่อ 61) ทิ้งห่าง Grok 4.5 High (56) อย่างชัดเจน
- **พฤติกรรมที่ดีขึ้นกับงานยาวๆ**: ในงานที่ใช้หลายขั้นตอน โมเดลจะทดสอบและตรวจสอบงานของตัวเองมากขึ้นก่อนไปต่อ
- **งาน Visual/Interactive ที่ดีขึ้นตั้งแต่รอบแรก**: โมเดลสามารถวางโครงสร้างและภาษาภาพของแอปได้ในรอบเดียว เหมาะกับการเริ่มจากไอเดียคร่าวๆ ไปสู่เวอร์ชันแรกที่ใช้งานได้

| Benchmark | Grok 4.6 | Grok 4.5 |
| --- | --- | --- |
| AA Intelligence Index | 61 | 56 |
| GDPVal-AA v2 | 1753 | 1526 |
| CursorBench v3.2 | 69.9% | 66.7% |
| DeepSWE v1.1 | 65.9% | 54% |
| FrontierCode v1.1 (Extended) | 61.3% | 56.6% |

## ราคา

Grok 4.6 ตั้งราคาเท่ากับ 4.5: **$2 ต่อ 1M input tokens และ $6 ต่อ 1M output tokens** (มีเวอร์ชัน fast ที่ราคา 2 เท่า) ใช้งานได้ผ่าน API ของ xAI, Cursor, Grok Build และพาร์ทเนอร์อย่าง OpenRouter, Vercel และ Cloudflare

บน MuiRouter `grok-4.6` คิดค่าใช้จ่ายตามราคาอย่างเป็นทางการพร้อม markup 1.05: **$2.10 / $6.30 ต่อ 1M tokens**

## สรุป

Grok 4.6 คือม้าศึกด้าน Agent ของตระกูล Grok: งานยาวหลายขั้นตอน งานข้าม codebase และโปรเจกต์ Visual/Interactive คือสนามที่มันถนัดที่สุด ลองใช้เลยวันนี้ทั้งใน Playground ของ MuiRouter, Agent ในเทอร์มินัลของคุณ หรือผ่าน API ที่เข้ากันได้กับ OpenAI — คิดเงินตามการใช้งานจริง โปร่งใส ไม่มีค่าสมาชิกรายเดือน
